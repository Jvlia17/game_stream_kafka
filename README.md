# GameStream — Real-Time Event Streaming & Cheat Detection

**Apache Kafka | Flink | Docker | Amazon MSK | Amazon EC2 | Amazon S3 | AWS Glue | AWS Lambda | Athena | Amazon SNS**

A streaming data pipeline for near-real-time cheat detection and cost-efficient gameplay analytics.


# Business Problem

An online gaming company continuously streams gameplay logs and needs to **detect suspicious player behavior in near real time**, automatically notifying its team when potential cheating is detected. It also needs to **store raw logs** cost-effectively, optimize them for analytical queries, and support **historical analysis** using SQL.

---

# My approach

To tackle this problem, I have used many different AWS services. 

- Apache Kafka (Amazon MSK)
- Amazon S3
- Apache Flink
- AWS Lambda and Amazon SNS
- AWS Glue
- Amazon Athena
